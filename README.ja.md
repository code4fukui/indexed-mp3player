# indexed-mp3player

ブラウザ上で動作するシンプルなMP3プレイヤーです。IndexedDB APIを使用して音楽ライブラリをローカルに保存し、セッションをまたいでも継続して再生できます。

## 機能

-   **ドラッグ＆ドロップでの追加:** ブラウザウィンドウにMP3ファイルを直接ドラッグしてライブラリに追加できます。
-   **永続ストレージ:** IndexedDBを活用して音声ファイルを保存するため、ブラウザのタブを閉じた後でもプレイリストが維持されます。
-   **再生コントロール:** 再生、停止、およびプレイリスト全体のクリアを行う標準的なコントロールが用意されています。
-   **トラックの直接選択:** リスト内の任意のトラックをクリックして即座に再生できます。
-   **連続再生:** 現在の曲が終了すると、リストの次の曲が自動的に再生されます。
-   **セッションの再開:** アプリケーションを再度開いた際、最後に再生したトラックを記憶し、ハイライト表示します。

## 使い方

1.  モダンブラウザで `index.html` ファイルを開きます。
2.  メインコンテンツ領域にMP3ファイルをドラッグ＆ドロップします。ファイルはブラウザのデータベースに保存され、プレイリストに表示されます。
3.  任意のトラック名をクリックして再生を開始します。
4.  `PLAY` ボタンをクリックすると、現在選択されているトラックの再生を開始または再開します。
5.  `STOP` ボタンをクリックすると、再生を一時停止します。
6.  `CLEAR` ボタンをクリックすると、保存されているすべてのトラックをストレージから完全に削除します。

## 使用ライブラリ

このアプリケーションは以下のオープンソースライブラリを使用して構築されています:

-   [IndexedDB](https://github.com/code4fukui/IndexedDB): IndexedDB APIのPromiseベースのラッパー。
-   [IndexedStorage](https://github.com/code4fukui/IndexedStorage): IndexedDB用のシンプルなKey-Valueストアラッパー。
-   [dataencoder](https://github.com/code4fukui/dataencoder): バイナリデータをデータURLにエンコードするユーティリティ。
